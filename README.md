# StudyPhoto 📸

授業中のスライドや板書を撮影するための、一時保存用「使い捨て」カメラアプリです。

## 💡 アプリの目的と概要
授業やセミナーの資料をスマホで撮影すると、iPhoneの標準カメラロール（写真アプリ）がスライドの画像で埋め尽くされてしまい、プライベートな写真と混ざって整理が面倒になります。

**StudyPhoto** は、撮影した画像を**アプリ内の専用領域（ローカルフォルダ）にのみ一時保存**し、授業中の振り返りに使用します。授業が終了したら、ワンタップで保存した一時画像をすべて物理削除できる、容量と写真アプリに優しい設計のアプリです。

---

## ✨ 主な機能

- **📸 高速カメラ起動**：アプリ起動と同時にカメラが立ち上がり、すぐにシャッターを切ることができます。
- **🔍 5段階ズーム切り替え**：シャッターボタン上のボタンをタップするだけで、`1.0x` ➔ `2.0x` ➔ `3.0x` ➔ `3.5x` ➔ `4.0x` と倍率をワンタップで切り替え可能。遠くの黒板やスライドもクリアに撮影できます。
- **🖼️ ギャラリー＆プレビュー表示**：
  - **タップ**：撮影した画像をフルスクリーンで拡大表示し、細かい文字を確認できます。
  - **長押し**：後で見返したい大切な画像だけを、iPhoneの標準「写真」アプリへエクスポート（保存）できます。
- **🗑️ 授業終了（一括削除）**：メイン画面上部の「授業終了」ボタンから、一時保存されたすべての画像データをストレージから物理削除します。
- **🚨 消し忘れ防止アラート**：前回起動時に削除し忘れた画像が残っている場合、アプリ起動時に「前回の画像を削除して新しく始めますか？」と確認するアラートを表示します。

## 🛠️ 技術スタック
- **フレームワーク**: [React Native](https://reactnative.dev/) (with [Expo SDK 54](https://expo.dev/))
- **言語**: TypeScript
- **主なライブラリ**:
  - `expo-camera` (カメラプレビュー・撮影制御)
  - `expo-file-system/legacy` (アプリ専用領域へのファイル入出力)
  - `expo-media-library` (標準カメラロールへの書き出し)

## 🚀 起動・開発手順

### 前提条件
ローカルで起動してiPhone実機でテストするためには、iPhoneに App Store から **[Expo Go](https://apps.apple.com/app/expo-go/id984023095)** アプリをインストールしておく必要があります。

### 1. 依存関係のインストール
プロジェクトのルートディレクトリで以下のコマンドを実行します。

```bash
npm install
```

### 2. 開発サーバーの起動
以下のコマンドでExpo開発サーバーを立ち上げます。

```bash
npm start
```
または、キャッシュをクリアして起動する場合：
```bash
npx expo start --clear
```

### 3. 実機で確認
1. ターミナルに巨大な **QRコード** が表示されます。
2. iPhoneの標準カメラアプリでそのQRコードをスキャンします。
3. 表示される通知をタップして **Expo Go** アプリで開くと、アプリがiPhone上で起動します！
