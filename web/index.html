GET STARTED · WEB

まずはここから

Safariで開くWeb版
Expo Goもログインも不要です

iPhone / Safari · StudyPhoto Web

このページも撮影アプリもブラウザだけで開けます。追加アプリ・Expoアカウント・VPNは不要です。
検索エンジンに掲載しない設定ですが、リンクの転送先も閲覧できます。カメラの利用にはHTTPSとアクセス許可が必要です。

  1. 1

    StudyPhotoを開く

    iPhoneのSafariで下のボタンを押してください。PCでこのページを見ている場合は、QRコードをiPhoneの標準カメラで読み取ります。

    ブラウザでStudyPhotoを開く ↗

    LINEやDiscord内のブラウザでカメラが開かない場合は、メニューからSafariで開き直してください。

  2. 2

    カメラを許可する

    撮影画面の「許可する」を押し、ブラウザのカメラへのアクセスを許可します。前回の写真が残っているときは「そのまま残す」か「削除して始める」を選びます。

  3. 3

    最初の1枚を撮る

    白い丸を押すと、このブラウザ内に写真を一時保存します。写真アプリには自動保存されず、画像をサーバーへ送信しません。

Web版のソースをダウンロード

ZIPを展開して、study_photo_webフォルダを開きます。PCにNode.js（22.13以降）を入れ、そのフォルダで npm ci → npm start を実行すると開発画面を開けます。

Web版をダウンロード ZIP↓

公開用は npm run build で生成する dist/ です。GitHub PagesなどのHTTPSサイトから配信すれば、PCの開発サーバーを止めても使えます。

友達に送るリンク

使い方はこの3つ

難しい設定はなし
授業の流れにそのまま

今日の板書1.0x
STEP 01

白いボタンで撮る

板書やスライドに向けて、下の白い丸をタップ。写真はブラウザ内だけに一時保存されます。

スライダーのつまみを左右に動かすと、1.0x〜4.0xの範囲でデジタルズームを連続調整できます。拡大するほど撮影に使う範囲が小さくなるため、文字の鮮明さを確認してください。

✓
選択した写真を保存
STEP 02

見返して必要な分だけ保存

右下の「ギャラリー」から一覧へ。写真をタップすると大きく表示され、1倍では左右のスワイプで前後の写真を確認できます。2本指で拡大・縮小（1〜4倍）し、拡大中は指で表示位置を動かせます。

「写真に保存」からiPhoneの共有メニューを開き、「画像を保存」を選びます。複数枚は「選択」や長押しで選び、保存ボタンを押してください。ファイル共有に未対応のブラウザではダウンロードします。

✓
今日の授業おつかれさま
STEP 03

終わったらまとめて片づけ

プレビューは「✕ 閉じる」、一覧は「◀ カメラへ」で戻ります。上の「授業終了 (全削除)」→「削除する」で、アプリ内の一時写真をすべて削除。

写真アプリへ保存した画像は残ります。アプリを閉じるだけでは一時写真は消えません。次の起動時に、残すか削除するか確認されます。

＋01

1枚をそのままコピー

写真をタップしてプレビューを開き、下の「コピー」を押すと画像がクリップボードへ。「コピー完了」が出たら、画像の貼り付けに対応したノートやメッセージアプリで貼り付けできます。

コピー写真に保存

コピーは写真アプリへの保存とは別です。残したい写真は「写真に保存」を使ってください。

＋02

いらない写真だけ削除

一覧の「選択」または長押しで選択モードへ。削除したい写真を選び、「選択した N 枚を削除」→「削除する」で、その写真だけをアプリ内から削除できます。

選択した 2 枚を削除完了

選択モードを終えるには右上の「完了」。写真アプリに保存済みの画像は、選択削除でも残ります。

! 一度消した一時写真は元に戻せません。共有メニューで実際に保存できたことを確認してから削除してね。

iPHONE HOME SCREEN

ホーム画面からすぐに開く

Safariの「ホーム画面に追加」で、StudyPhoto Webを直接開くアイコンを作れます。Expo Goやショートカットアプリは不要です。

  1. 1

    撮影画面をSafariで開く

    上の「ブラウザでStudyPhotoを開く」ボタンから撮影画面へ進みます。ホーム画面に追加するのは案内ページではなく、撮影画面です。

  2. 2

    ホーム画面に追加する

    Safariの共有メニューから「ホーム画面に追加」を選び、名前をStudyPhotoにして「追加」をタップします。

  3. 3

    アイコンから撮影を始める

    追加したアイコンをタップし、必要に応じてカメラを許可してください。Safariのタブとホーム画面から開くアプリで保存領域が異なる場合は、写真がある方で保存・削除してください。

一時写真は長期保存用ではありません。
ブラウザのデータ消去・プライベートモード・端末の空き容量不足で失われることがあります。必要な写真は先に保存してください。初回起動にはインターネット接続が必要で、オフライン起動は保証しません。

GOOD TO KNOW

ちょっと気になること

困ったときはここをチェック

iPhoneの「写真」にも自動で保存される？

撮影しただけでは保存されません。「写真に保存」で共有メニューを開き、「画像を保存」を選びます。共有メニューを閉じただけでは保存済みとは限らないので、写真アプリで確認してください。

保存する写真の画質は？

ブラウザのカメラ映像からJPEG最高品質で保存します。解像度は端末とブラウザの映像ストリームに依存し、iPhoneの標準カメラと同じ画質・画素数を保証しません。デジタルズームでは中央部分を切り取ります。

カメラが開けないときは？

HTTPSのページをSafariで開き、サイトのカメラアクセスを許可してください。他のアプリがカメラを使っている場合は閉じてから再試行します。LINEやDiscord内のブラウザではSafariで開き直してください。Expo Goへのログインは不要です。

コピーや保存が使えないときは？

画像のコピー・ファイル共有はブラウザごとに対応状況が違います。コピーの許可を確認するか、写真の保存・共有を使ってください。ファイル共有に未対応の場合はダウンロードします。

アプリを閉じると写真は消える？

通常は同じブラウザで次に開いたときも残り、起動時に削除するか確認されます。ただしブラウザのデータ消去や自動整理で失われる可能性があります。残したい写真は先に保存してください。

写真はどこに置かれる？

このブラウザの端末内保存領域（IndexedDB）に置きます。撮影画像をサーバーへアップロードする処理はありません。Safariのタブとホーム画面アプリ、別のブラウザでは保存領域が異なる場合があります。

シャッター音は鳴らない？

このWebアプリはシャッター音を再生しません。ただし端末やブラウザの動作音まで保証するものではありません。授業の撮影ルールに従ってください。
