まずはここから

Expo Goで開くソースコード版
App Store配布のStudyPhotoではありません

iPhone / Expo SDK 57

この案内ページはSafariやChromeで開けます。閲覧に追加アプリやVPNは不要です。検索エンジンに掲載しない設定ですが、リンクの転送先も閲覧できます。
撮影アプリ本体は Expo SDK 57版です。使うにはiPhoneにSDK 57対応のExpo Goを入れてください。

  1. 1

    Expo Goを入れる

    App StoreからExpo Goをインストール。すでに入っている場合も、SDK 57対応版に更新してください。

    App StoreでExpo Goを入れる ↗Expo GoとStudyPhotoのSDKバージョンが合っている必要があります。
  2. 2

    StudyPhotoを開く

    このページのQRコードをiPhoneの標準カメラで読み取り、通知をタップしてExpo Goで開きます。iPhoneでこのページを見ている場合は、下のボタンから開けます。

    iPhoneのExpo Goで開く ↗

    このページには起動リンクが設定されていません。配布者から起動リンク付きのページを受け取ってください。自分で起動する手順は下の「PCから起動・共有する人へ」にあります。

    配布者の開発サーバーが起動している間だけ開けます。LAN接続ではPCとiPhoneを同じWi-Fiにつないでください。
  3. 3

    カメラを許可する

    「許可する」をタップして、カメラへのアクセスを許可。前回の画像が残っているときは、最初に「そのまま残す」か「削除して始める」を選びます。

アプリ一式をダウンロード

ZIPをすべて展開して、study_photoフォルダを開きます。Windows / Mac / LinuxのPCにNode.js（22.13以降）を入れ、そのフォルダでターミナルを開いて npm ci → npm run share を実行してください。

アプリ一式をダウンロード ZIP↓

現在のSDK 57版ソースコードです。スマホにZIPを入れるだけでは動きません。表示されたQRコードをiPhoneの標準カメラで読み取ってください。共有用サーバーは配布者のExpoアカウントを使わずに起動し、別のWi-Fiからも接続できます。使用中はPCと開発サーバーを起動したままにします。

友達に送るページを作る

Expoの起動URL（exp://…）を下の欄に貼り付けて共有リンクを作り、友達に送ってください。この公開ページを見るための追加アプリやVPNは不要ですが、撮影にはExpo Goが必要です。配布者と同じExpoアカウントのログインを要求しない共有には、npm run shareで表示されるURLを使います。

exp:// または exps:// のURLのみ対応。起動リンクを知っている人は、サーバー稼働中のアプリにアクセスできます。

STEP 01

白いボタンで撮る

起動するとカメラ画面へ。板書やスライドに向けて、下の白い丸をタップ。写真はアプリ内だけに一時保存されます。

シャッター上のスライダーのつまみを左右にスワイプすると、1.0x〜4.0x の範囲で倍率を連続調整できます。タップでの段階切り替えではありません。表示倍率は目安で、実際のズームは端末によって異なります。

選択した 1 枚をカメラロールへ保存
STEP 02

見返して必要な分だけ保存

右下の「ギャラリー」から一覧へ。写真をタップすると大きく表示され、左右にスワイプして前後の写真を確認できます。「写真に保存」でその1枚を写真アプリへ。

まとめて保存するなら、一覧の「選択」または写真の長押しから選択モードへ。写真をタップして選び、下の「カメラロールへ保存」を押します。初回は写真へのアクセスを許可してください。

今日の授業おつかれさま
STEP 03

終わったらまとめて片づけ

プレビューは「✕ 閉じる」、一覧は「◀ カメラへ」で戻ります。上の「授業終了 (全削除)」→「削除する」で、アプリ内の一時写真をすべて削除。

写真アプリへ保存した画像は残ります。アプリを閉じるだけでは一時写真は消えません。次の起動時に、残すか削除するか確認されます。

＋01

1枚をそのままコピー

写真をタップしてプレビューを開き、下の「コピー」を押すと画像がクリップボードへ。「コピー完了」が出たら、画像の貼り付けに対応したノートやメッセージアプリで貼り付けできます。

コピー写真に保存

コピーは写真アプリへの保存とは別です。残したい写真は「写真に保存」を使ってください。

＋02

いらない写真だけ削除

一覧の「選択」または長押しで選択モードへ。削除したい写真を選び、「選択した N 枚を削除」→「削除する」で、その写真だけをアプリ内から削除できます。

選択した 2 枚を削除完了

選択モードを終えるには右上の「完了」。写真アプリに保存済みの画像は、選択削除でも残ります。

! 一度消した一時写真は元に戻せません。大切な写真は「保存完了」を確認してから削除してね。

iPHONE SHORTCUT

ホーム画面からすぐに開く

iPhoneの「ショートカット」アプリで、StudyPhotoの起動URLを開くショートカットを作ります。授業前にアイコンをタップするだけで、Expo Goへ。

  1. 1

    Expoの起動URLを用意する

    まずは上の起動手順で、StudyPhotoを開けることを確認してください。使うのは exp:// または exps:// で始まるExpoの起動URLです。このサイトの https:// の共有ページURLとは別です。

    このページには起動URLが設定されていません。配布者からExpoの起動URLを受け取るか、「PCから起動・共有する人へ」で起動URL付きのページを作ってください。

    この欄を長押しして「すべてを選択」→「コピー」。共有ページのURLではなく、ここに表示された起動URLを使ってください。

  2. 2

    新しいショートカットを作る

    iPhoneで「ショートカット」アプリを開き、右上の「＋」をタップ。上部の名前のメニューから「名称変更」を選び、StudyPhoto など分かりやすい名前を付けます。

  3. 3

    「URL」→「URLを開く」を追加する

    「アクションを追加」や下部の検索欄で URL を検索し、「URL」アクションを追加。そのURL欄に、手順1の起動URLを貼り付けます。続けて URLを開く を検索し、その下に追加してください。

    1URL 受け取ったExpoの起動URL

    2URLを開く 直前の「URL」を開く

    実行ボタン（▶）を押して、StudyPhotoが開くか確認します。アプリを開く確認が表示されたら、内容を確認して許可してください。「アプリを開く」でExpo Goだけを指定する方法とは違い、StudyPhotoの起動URLを開きます。

  4. 4

    ホーム画面に追加する

    ショートカットを保存し、一覧の「…」から編集画面を開きます。上部の名前の横のメニューから「詳細」または「ホーム画面に追加」を開き、表示名を StudyPhoto にして「追加」をタップ。アイコンも好みの画像に変更できます。

    次からはホーム画面のアイコンで起動できます。iOSのバージョンによってメニューの位置や表示が異なる場合は、下のApple公式ガイドを確認してください。

ショートカットは、起動への近道です。
StudyPhotoのインストールやオフライン化は行いません。SDK 57対応のExpo Goと、起動中の開発サーバーが必要です。LAN接続ではPCとiPhoneを同じWi-Fiにつないでください。サーバーの起動URLが変わったら、ショートカットの「URL」も新しいものに貼り替えます。Safariでこのサイトをホーム画面に追加するだけでは、StudyPhotoを直接起動するショートカットにはなりません。

Apple公式：ショートカットを作成する / ほかのアプリのURLスキームを使う / ホーム画面に追加する

GOOD TO KNOW

ちょっと気になること

困ったときはここをチェック

iPhoneの「写真」にも自動で保存される？

撮影しただけでは保存されません。プレビューの「写真に保存」、または一覧で選択して「カメラロールへ保存」を押した画像だけが、iPhoneの写真アプリに保存されます。

保存する写真の画質は？

新しく撮る画像はJPEGの最高品質設定を使い、保存時にStudyPhoto側で縮小・再JPEG圧縮は行いません。ファイル容量は増える可能性があります。すでに保存した画像の画質は変わりません。画素数は端末や撮影処理に依存します。ピントや手ぶれ、強いズームによるぼやけは直せないため、文字を鮮明に撮るには倍率を抑え、ピントが合ってから撮影してください。

Expo Goで開けないときは？

iPhoneのExpo GoがSDK 57対応版か確認し、配布者に開発サーバーが起動中か確認してください。「Sign in to Expo Go as …」と出る場合は、配布者が npm run share で起動し、新しいURLから共有リンクを作り直してください。配布者のアカウントでログインする必要はありません。古いリンクではなく、更新されたページのQRか起動ボタンから開き直します。LANの起動URLはPCと同じWi-Fiが必要です。PCやサーバーを止めると開けなくなります。

カメラや写真へのアクセスを断ってしまったら？

iPhoneの「設定」でExpo Goのカメラ・写真の権限を確認して、許可してください。アプリに戻って撮影・保存をやり直します。専用のiOSビルドを使っている場合は、StudyPhotoの権限を確認してください。

アプリを閉じると写真は消える？

閉じただけでは消えません。次の起動時に「前回の画像が残っています」と表示されます。見返したり保存したりしたい場合は「そのまま残す」、不要なら「削除して始める」を選んでください。授業が終わったら「授業終了 (全削除)」でも片づけられます。

写真はどこに置かれる？

写真は端末内のアプリ専用領域に保存されます。StudyPhotoには写真をサーバーへアップロードする処理はありません。アプリの削除やExpo Goのデータ消去で失われるため、残したいものは写真アプリに書き出してください。

シャッター音は鳴らない？

撮影時はシャッター音を無効にする設定を使っています。ただし、端末やOSの制約で音が鳴る場合があります。無音を保証するものではないので、使うiPhoneで事前に確認し、授業の撮影ルールに従ってください。
